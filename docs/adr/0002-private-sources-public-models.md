# Sources stay private; the published Library is FoldLab's own words

FoldLab lives in the Dobrinska Arcade, which is public on GitHub Pages. Most good diagrams belong to their designers, so Sources (diagram images, PDFs, photos of his books) never leave the parent's computer. The published Library holds only FoldLab's own fold sequences, with Step text written in FoldLab's own words and nothing copied from a Source. Designer Models are included: for an unlisted family app that is an accepted, low (not zero) risk.

## Considered Options

- **Private hosting over Tailscale**: rejected in favour of living in the Arcade with the kids' other Games.
- **Publish traditional Models only**: the zero-risk fallback if designer Models ever become a problem.
